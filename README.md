# ORBIT — Personal Command Center

A privacy-first personal workspace for tasks, focus sessions, and quick notes. ORBIT is designed to run in your browser without an account, API key, or backend.

**Live demo:** https://orbit-command-center-nawaid333.vercel.app

## Features
- Task manager: add, complete, and delete tasks
- Focus timer: 25-minute sessions
- Quick notes with automatic browser saving
- Dashboard overview and responsive layout
- Local-first operation with no sign-in required

## Run locally
Clone the repository and open `index.html` in a browser. You can also run `python -m http.server 8000` in the project folder and visit `http://localhost:8000`.

## Privacy
Tasks and notes are stored in browser local storage on the device where you use ORBIT. They do not sync across devices. Clearing browser data may erase locally stored information. Do not store passwords or other sensitive information in notes.
