# Contributing to ORBIT

Thanks for considering a contribution.

## Before you start
- Open an issue to describe a significant feature or change before implementing it.
- Keep the app local-first and usable without an account or paid API.
- Never commit API keys, passwords, personal data, or environment files.

## Pull requests
1. Fork the repository and create a focused branch.
2. Make a small, clearly scoped change.
3. Test the app in a current desktop and mobile browser.
4. Describe what changed and include screenshots for visual changes.

Please keep accessibility, responsive behavior, and data privacy in mind.
